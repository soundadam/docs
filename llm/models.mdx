钱包与价格按人民币（CNY）显示，最低充值 1 元。

## 计费口径

- **人民币结算，1:1**：`USDExchangeRate = 1`、`Price = 1`。充值 ¥N 到账 ¥N 额度，不按汇率跳变。
- **按模型倍率计价**，对标 micu 中转站的费率表：
  - 单价基准：模型倍率 `1` = ¥2 / 100 万输入 token。
  - 对话 / Codex 模型：模型倍率 `0.1`，即 **¥0.20 / 100 万输入 token**。
  - `gpt-oss-120b-medium`：模型倍率 `0.5`（¥1.00 / 100 万输入 token）。
  - 补全倍率按模型族取 `6` 或 `8`，作用于输出 token（`gpt-oss-120b-medium` 为 `2.76`）。
  - 生图模型按张计费，每张 ¥0.1。
- **分组倍率**：付费分组默认 `1`，不作加价杠杆；`codex-cheap` 例外，整体 `0.45`。
- 实时数字以控制台「模型广场」为准。

```
输入扣费 = 输入 token × 模型倍率 × 分组倍率 × (¥2 / 1M)
输出扣费 = 输出 token × 模型倍率 × 补全倍率 × 分组倍率 × (¥2 / 1M)
生图扣费 = 每张单价 × 分组倍率
```
