Base URL：`https://llm.soundadam.com`

- **Claude Code / Anthropic 协议**：`ANTHROPIC_BASE_URL` 直接填主机，**不加 `/v1`**。
- **Codex CLI / OpenAI 协议**：`base_url` 填 `https://llm.soundadam.com/v1`，**要带 `/v1`**。

最常见的错误就是把这两条弄反：Claude 的地址误加 `/v1`，Codex 的地址漏掉 `/v1`。

这是对外的 NewAPI 中转站。WordPress（`https://soundadam.com`）是工作室站点与付费入口，不是这份手册。实验室（课题组）密钥在 `https://llm2.soundadam.com`（Bifrost + Keycloak），不在本站注册，也不在本手册范围。控制台「Docs」按钮打开本站（`https://docs.llm.soundadam.com`）。

## 30 秒上手

<Steps>
  <Step title="注册">
    在 `https://llm.soundadam.com` 用密码或 GitHub 登录。新账户额度为 0。密码注册会收到验证信，发件人是 `soundadam <no-reply@soundadam.com>`。
  </Step>
  <Step title="充值">
    付费入口：`https://soundadam.com/pricing/`。钱包按人民币（CNY）显示。
  </Step>
  <Step title="建令牌">
    控制台「令牌」→「新建」。主力选 `gemini` / `codex` / `image`（0.5 倍）。不要停在 `default`（官方默认价，仅 Gemini），不要选 `lab`。令牌形如 `sk-xxxxxxxx`。
  </Step>
  <Step title="接客户端">
    把主机和令牌填进客户端。协议决定要不要带 `/v1`（见上）。
  </Step>
</Steps>

### 三条快速路径

<CodeGroup>

```bash Claude Code
npm install -g @anthropic-ai/claude-code

export ANTHROPIC_BASE_URL="https://llm.soundadam.com"
export ANTHROPIC_AUTH_TOKEN="sk-你的令牌"      # 令牌分组：codex（GPT）或 gemini

claude
# 进入后执行 /model gpt-5.6-sol 切到本站模型
```

```bash Codex CLI
npm install -g @openai/codex

# ~/.codex/config.toml 见 Codex CLI 页；令牌分组：codex
export SOUNDADAM_API_KEY="sk-你的令牌"

codex
```

```bash curl 冒烟
# 令牌分组：codex
curl -sS https://llm.soundadam.com/v1/chat/completions \
  -H "Authorization: Bearer sk-你的令牌" \
  -H "Content-Type: application/json" \
  -d '{"model":"gpt-5.4-mini","messages":[{"role":"user","content":"ping"}],"max_tokens":8}'
```

</CodeGroup>

## 令牌分组

按号池选组，不要按「对话 / 生图」混用一把 key。

| 分组 | 用途 | 可外接 | 保证 |
| --- | --- | --- | --- |
| `default` | 新账号默认组，官方默认价。效果同 `gemini`，单价更高。不建议当主力 | — | — |
| `gemini` | Gemini 文本与 Gemini 生图，分组倍率 0.5 | 是 | — |
| `codex` | **Codex Pro / GPT 号池**，分组倍率 0.5 | 是 | 假一赔十 |
| `codex-cheap` | Codex 低价号池，分组倍率 0.45 | 是 | — |
| `image` | GPT Image 专用，**按张**计费，分组倍率 0.5 | 是 | — |
| `lab` | 运营把个别 GitHub 用户调成不扣费。公众不可选 | — | — |

没有公开的 `chat` 分组。Gemini 生图走 `gemini`，不要配 `image`。实时倍率与完整模型清单在登录后的控制台「模型广场」。分组用途见 [模型与分组](/models)。
