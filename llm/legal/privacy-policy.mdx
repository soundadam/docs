## 一、隐私

### 我们处理的数据

- 账号：用户名、邮箱（若使用密码注册并验证）、GitHub 账号绑定（若使用 GitHub 登录）。
- 用量：每次 API 调用的时间、模型、token 与额度扣减。用于计费、排障与滥用检测。
- 邮件：验证信由 Resend 代发，发件人为 `soundadam <no-reply@soundadam.com>`。
- 支付：若日后开通充值，支付与订单在集群外的收款进程处理；本站 NewAPI 不存放支付宝私钥。

我们不会把客户内容用于训练自己的模型。密钥泄露导致的调用，平台无法代你追认，请自行保管令牌。

### 保留与共享

数据保留在本站 NewAPI 及其 Postgres / Redis 中。发信经过 Resend。我们不会把账户名单卖给无关第三方。法律或监管要求披露时除外。

你可以通过本站账户功能停止使用。删除账号需联系运营，当前没有自助销户按钮。

## 二、使用政策

凡向本站提交内容或调用 API 的个人或组织，均须遵守以下限制。soundadam 可以检测、限制、暂停或终止违规访问，并拦截或过滤违规内容。

1. 不得违法，包括贩卖违禁品、人口贩运、侵犯知识产权，以及任何虐待、剥削或伤害未成年人的行为。
2. 不得攻击或破坏关键基础设施。
3. 不得开发或自动化未授权入侵、恶意软件、勒索软件、拒绝服务或绕过安全控制。
4. 不得用于开发、设计或获取武器、爆炸物或大规模杀伤性材料。
5. 不得煽动暴力或基于受保护特征的仇恨。
6. 不得跟踪、骚扰或非法收集他人隐私、生物特征或健康数据。
7. 不得制作或传播任何性化或虐待未成年人的内容。此类违规将立即封禁，并按法律移交。
8. 不得大规模生成用以造成心理伤害的内容（包括诱导自残或自杀）。
9. 不得大规模制造可能造成公共危害的虚假信息。
10. 不得用本服务破坏选举或公民程序，或大规模生成隐瞒来源的竞选材料。
11. 不得用于预测性执法、未经同意的大规模监视或政府审查工具。
12. 不得用于诈骗、钓鱼、伪造文件或垃圾信息。
13. 不得越狱、提示注入、盗取模型权重或训练数据，或绕过速率限制。
14. 不得生成性露骨内容（合法的性健康教育、科研或艺术讨论除外）。

高风险场景（法律意见、医疗诊断、保险核保、信贷、就业住房决定、招生考试、自动新闻发布）必须有合格人工审核，并在面向个人时披露其正在使用 AI。面向用户的聊天机器人须在会话开始时说明其不是真人。
